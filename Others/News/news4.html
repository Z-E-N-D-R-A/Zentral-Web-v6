ZENTRAL CHAT UPDATES
We are proud to present tons of new features to Zentral Chat that will improve the way you chat.

With our new feature commands, you can go beyond the limitations of a chat service, accessing third part applications while connecting with friends. To use commands, simply type "+", followed by command name (e.g. +level). Z.E.N.D.R.A, our friendly advanced bot will handle the rest, providing the information you requested. Here are all the commands you can use:
  • +levels (Show your current level)
  • +leaderboard (Top 10 highest level users)
  • +gif (Sends a GIF in the chat)
  • +brawl_tag (Save your Brawl Stars player tag)
  • +brawl_player (Get Brawl Stars player info)
  • +brawl_log (Get the most recent game history)
  • +brawl_club (Get Brawl Stars club info)
  • +brawl_events (Get current maps in Brawl Stars)
  • +brawl_leaderboard (View the top global leaderboard)
  • +brawl_brawlers (View the leaderboard for a Brawler)
  • +nasa_apod (Astronomy Picutre of the Day)
  • +nasa_moon (Random Moon image)
  • +nasa_iss (Current ISS location)

We know how important it is to clearly express yourself. And the best way to do so is with emojis. Local emoji lists might not be easily accessible, especially on laptops and PCs. Therefore, we built a Custom Emoji Menu on the input bar. To use it, you simply press the Emoji Menu Button (or Command/Ctrl + e), and select the emoji you are looking for. Our emoji menu includes cute custom text faces at the end, bringing in more options and more variaties. To make it easier to navigate, we have added footer indicators and search bar. It is easier than ever to use emojis on Zentral-Chat.

You can now mention a user by typing @(username), and see which user has read your message with read recipient. When there is a new message, a notification sound will be played and tab name will indicate how many new messages.
